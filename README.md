# Portafolio Personal - Verónica Guaymás

Portafolio Web Personal desarrollado para presentar mi perfil profesional, habilidades , proyectos y datos de contacto.

# Descripción

Este proyecto consiste en el desarrollo de un sitio web personal, donde presento mi perfil como Técnica Electrónica y Programadora.

El sitio cuenta con un diseño responsive que permite adaptar el contenido a diferentes tamaños de pantalla, incluyedo dispositivos moviles.

# Tecnologías Utilizadas 

- HTML
- CSS
- JAVASCRIPT
- GIT
- GITHUB
- XAMPP
- EMAILJS

# Funcionalidades

- Diseño responsive para escritorio, tablet y móvil.
- Menu de navegación.
- Secciones de presentacion personal.
- Galeria contenido personal.
- GAleria/ contenido visual.
- Formulario de contato
- Envio mensajes mediante EmailJS.
- Animaciones e interacciones con JavaScript
- Diseño realizado con CSS Grid y Flexbox.
